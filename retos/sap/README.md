# Reto: SAP

## Objetivo

Desarrollar integraciones y programas ABAP para un sistema SAP.

## Tareas

- Programa ABAP para reporte de materiales con ALV
- RFC function module para consulta de clientes
- BAPI para creación de órdenes de venta
- Idoc configuration para intercambio con EDI
- OData service para consumir desde externo
- CDS view con parámetros y asociaciones

## Criterios de evaluación

- ✅ Código ABAP sin errores de sintaxis
- ✅ RFC/BAPI funcionales y documentados
- ✅ Idoc estructura y segmentos correctos
- ✅ OData service retorna datos
- ✅ CDS view optimizada
