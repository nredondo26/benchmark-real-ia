# Reto: Bug Fixing

## Objetivo

Corregir bugs reales en una aplicación legacy. Se proporciona un código con errores intencionales que reflejan problemas comunes en producción.

## Bugs incluidos

- Race condition en operación concurrente
- SQL injection en query dinámica
- Memory leak en manejador de eventos
- Off-by-one en lógica de paginación
- Error de tipado en función crítica

## Criterios de evaluación

- ✅ Cantidad de bugs corregidos
- ✅ Las correcciones no introducen nuevos bugs
- ✅ Tests existentes siguen pasando
- ✅ Código legible y mantenible

## Tiempo esperado

20-40 minutos.
