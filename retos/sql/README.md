# Reto: SQL

## Objetivo

Optimizar queries lentas y modelar datos para un sistema de e-commerce.

## Tareas

1. **Modelado**: Diseñar esquema para productos, clientes, órdenes y pagos
2. **Optimización**: Reescribir 5 queries lentas para que usen índices adecuados
3. **Migración**: Escribir script de migración con 10,000 registros de prueba
4. **Análisis**: Generar reporte de ventas por mes/categoría
5. **Integridad**: Agregar constraints y triggers necesarios

## Criterios de evaluación

- ✅ Esquema normalizado (3FN)
- ✅ Queries optimizadas (EXPLAIN ANALYZE)
- ✅ Migración se ejecuta sin errores
- ✅ Reporte generado correctamente
- ✅ Constraints y triggers funcionan
