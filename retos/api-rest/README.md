# Reto: API REST Completa

## Objetivo

Crear una API REST funcional para un sistema de gestión de tareas (Task Manager) con las siguientes características:

- CRUD de tareas (crear, leer, actualizar, eliminar)
- Autenticación JWT
- Base de datos (PostgreSQL o SQLite)
- Documentación con Swagger/OpenAPI
- Tests unitarios y de integración

## Lenguajes permitidos

Python (FastAPI/Flask), Node (Express/NestJS), Go (Gin), Java (Spring Boot), o Rust (Actix).

## Criterios de evaluación

- ✅ Compilación/ejecución exitosa
- ✅ Todos los endpoints funcionan según especificación
- ✅ JWT implementado correctamente
- ✅ Tests pasan
- ✅ Código limpio y estructurado
- ✅ Documentación de API

## Tiempo esperado

30-60 minutos para un modelo competente.

## Archivos

- `spec.yaml` — Especificación OpenAPI del reto
- `tests/` — Pruebas que debe pasar la solución
