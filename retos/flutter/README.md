# Reto: Flutter

## Objetivo

Crear una aplicación móvil en Flutter para llevar un registro de hábitos diarios.

## Funcionalidades

- Lista de hábitos con check-in diario
- Estadísticas semanales (gráfico de barras)
- Notificaciones push locales
- Persistencia con SQLite (sqflite)
- Tema claro/oscuro
- Animaciones en transiciones

## Criterios de evaluación

- ✅ Aplicación compila y corre en Android/iOS
- ✅ UI funcional y responsive
- ✅ Datos persisten entre sesiones
- ✅ charts/gráficos implementados
- ✅ Código sigue convenciones de Dart/Flutter
